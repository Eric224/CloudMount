# 0.4.12：行動版瀏覽與快取

## 使用方式

在 CloudMount 右上角「關於 → 瀏覽與快取」可開關圖片縮圖、設定縮圖容量（16–128 MB，預設 64 MB）與閒置保留天數（1–30 天，預設 7 天），或只清除 CloudMount 的縮圖快取。設定需按「儲存設定」。這些操作不會刪除遠端文件、待上傳修改或由「檔案」管理的下載副本。

S3 新增表單的儲存桶名稱為必填。進階設定可填路徑前綴並選擇路徑式或網域式 URL。舊連線維持原來的路徑式與整個儲存桶，不會因更新而改變掛載內容。更換儲存桶應新增另一個空間，避免將原有 File Provider 項目識別碼指向不同的文件。

## 已實作

- 普通 S3 空間透過 ListObjectsV2 按頁列目錄，每頁最多 200 項，直接交給 File Provider。畫面不再必須等整個 S3 目錄讀完。
- 分頁會檢查重複或循環 token、重複／大小寫衝突名稱、最大項目數、掃描有效時間、取消與逾時。
- 只有所有頁都成功，才移除本機索引中遠端已刪除的舊項目。中途失敗、取消或本機同時編輯，都不會把未讀到的項目誤判為刪除。
- 完整目錄與已核實的項目資訊短暫重用約 60 秒，減少重複 LIST / HEAD。快取命中不會被宣稱為新的成功遠端連線。
- WebDAV、Drime、FTP、FTPS、SFTP 及保險箱沿用各協議有限制的目錄讀取，再以 File Provider 頁面交付；同樣重用短期目錄與檔案資訊。這些路徑並非全部具備伺服器逐頁讀取。
- 實作 NSFileProviderThumbnailing，僅處理系統當下要求的圖片，不遞迴掃描或預先下載整個空間。
- 圖片降採樣至最多 512 像素，原檔最多 8 MiB、解碼來源最多 6,000 萬像素／單邊 20,000 像素。支援 JPEG、PNG、HEIC/HEIF 等 ImageIO 可解碼的常見圖片；不背景處理影片、PDF、超大圖或損壞圖片。
- 同一批最多 128 個識別碼、最多兩批等待工作；跨 App 與擴充一次只產生一張縮圖。工作有總時間限制與取消回呼，整批完成回呼僅執行一次。
- 按位置、項目 ID、路徑、版本、大小、修改時間與尺寸建立雜湊快取鍵。覆寫／修改被重新核實後產生新縮圖；並發要求透過共用鎖重用結果。
- FTP/SFTP 的大小與粗略修改時間不是強內容版本，因此過期預覽會重新讀取原圖，不會只憑相同大小與時間永久重用。
- 縮圖快取採有容量、數量（最多 512 份）及閒置期限限制的 LRU 清理。普通快取使用私有權限；iOS 設定完整檔案保護並排除備份。
- 保險箱縮圖另外以 CryptoKit AES-GCM 加密，金鑰由已解鎖的保險箱金鑰透過獨立 HKDF 用途衍生，不額外詢問密碼。上鎖後無法讀取快取，且交付縮圖回呼前再次持鎖驗證，防止「產生完成後才上鎖」的競態。
- 暫存原圖置於受保護的每位置 scratch 目錄，正常結束即移除；保險箱上鎖也清理該位置 scratch。
- 原圖讀取經過大小限制與前後版本檢查；一般檔案下載也補上實際位元組長度檢查，截斷回應不會當成正常文件交給「檔案」。
- 可選縮圖讀取失敗不會寫成整個雲端的持續同步警告。
- 新欄位、說明與設定頁均提供繁中、簡中與英文；未支援的系統語言退回英文。

## 必須了解的範圍

第一次產生縮圖仍可能下載原圖。S3、WebDAV、FTP、SFTP 沒有通用的遠端縮圖 API，本版不宣稱只需下載遠端小圖。系統可能另外保留已經顯示的縮圖或預覽；CloudMount 的上鎖與清理無法保證抹除系統或其他 App 的副本。

快取不等於完整離線同步。第一次伺服器清單本身逾時時，快取不能產生尚未取得的清單；仍需要修正遠端服務或 gateway。跨裝置修改可能在短暫快取過期後才出現。保險箱格式維持標準 Cryptomator，沒有資料轉換。

## 驗證

Swift 核心測試覆蓋 S3 舊設定遷移、路徑編碼、分頁失敗不刪除、同時本機修改保留、快取與並發合併、覆寫失效、保險箱快取加密與鎖定、過期的 FTP/SFTP 預覽、損壞資料、容量清理、逾時與截斷下載。

`Testing/browsing-fixture.py` 僅綁定本機 19474 埠，使用記憶體假資料與測試金鑰，驗證實際 SigV4、九頁清單、前綴隔離與有條件覆寫／複製／刪除。使用 `CLOUDMOUNT_RUN_BROWSING_HTTP_TESTS=1` 啟用相應測試。它不是 App 的執行依賴，也沒有降低生產連線的 HTTPS 憑證驗證。

iOS hosted tests 驗證真正的 File Provider 縮圖方法、有效圖片輸出、回呼順序與取消；UI tests 驗證必填／選填區分、三語設定頁與 iPad 版面。模擬器不模擬硬體檔案保護，因此模擬器檢查 POSIX 私有權限；硬體保護類別的斷言只適用真機測試。
